# Contributing to Synthetic Payment Data Generator
# Contribuyendo al Generador de Datos de Pago Sintéticos

## English

Thank you for your interest in contributing to this project! This document provides guidelines for contributing.

### How to Contribute

1. **Fork the repository**
   - Click the "Fork" button at the top right of the repository page

2. **Clone your fork**
   ```bash
   git clone https://github.com/YOUR_USERNAME/Synthetic-Payments-Data-Generator.git
   cd Synthetic-Payments-Data-Generator
   ```

3. **Create a new branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes**
   - Write clean, documented code
   - Add comments in both English and Spanish where appropriate
   - Follow the existing code style

5. **Test your changes**
   ```bash
   python src/test_models.py  # Run tests
   ```

6. **Commit your changes**
   ```bash
   git add .
   git commit -m "Add: Brief description of your changes"
   ```

7. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```

8. **Create a Pull Request**
   - Go to the original repository
   - Click "New Pull Request"
   - Select your fork and branch
   - Describe your changes

### Code Style Guidelines

- Use clear, descriptive variable and function names
- Include docstrings in both English and Spanish
- Follow PEP 8 style guidelines for Python code
- Keep functions focused and modular
- Add type hints where appropriate

### What to Contribute

We welcome contributions in many forms:

- **Bug fixes**: Fix issues in existing code
- **New features**: Add new generative models or data analysis features
- **Documentation**: Improve README, add tutorials, or create examples
- **Tests**: Add unit tests or integration tests
- **Visualizations**: Create new visualization types
- **Performance improvements**: Optimize existing code
- **Translations**: Help with bilingual documentation

### Reporting Issues

When reporting issues, please include:

- Python version
- Operating system
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Error messages (if any)

### Questions or Suggestions

Feel free to open an issue for:
- Questions about the project
- Suggestions for improvements
- Discussion of new features
